| 维度 | 账单 |
|---|---|
| **重复写库** | `signal_pnl` 21 次 × 493 行（幂等，无脏数据）✅ |
| **抢占锁** | 21 次 × 40~90 秒 → **直接导致 `EVENING_HITHINK` 被跳过 4 次** 🔴 |
| **日志噪音** | 21 × 15 行 ≈ **315 行 INFO**（占今晚日志 40%）|
| **DuckDB 写放大** | 每次全量重写 493 行 pnl + 18 行 se，**21 次** |
| **收益** | **0**（第一次跑完就够了，后 20 次全是浪费）|

**根因（代码级确认，两处）**：
```python
# ① auto_sniper_daemon.py:3570  —— 缺"已完成"判定
state_key_by_label = {
    "晚间增量同步": "last_sync_ok_bj_date",
    "晚间P1":     "last_p1_ok_bj_date",
    "晚间P5":     "last_p5_ok_bj_date",
    "晚间安全压缩": "last_daily_vacuum_bj_date",
    # ← "信号T+N回填" 不在这里 → 永远返回 False
}
# ② auto_sniper_daemon.py:3877  —— 写盘键名对不上
_write_pipeline_state_patch(
    last_signal_backfill_bj=_now_bj().isoformat(),   # ← 写这个
    # 判定查的是 last_signal_backfill_bj_date       ← 查那个
)
# ③ auto_sniper_daemon.py:3601 —— 进程内去重键含分钟戳
dispatch_key = f"{minute_key}:{hhmm}:{label}"       # minute_key=%Y%m%d%H%M → 每分钟都不同
```

**修复（两处，5 分钟）**：

# ② :3877 补写日期键（格式必须是 YYYYMMDD 8 位，与其它键一致）

    last_signal_backfill_bj=_now_bj().isoformat(),
    last_signal_backfill_bj_date=today,     # ← today = _now_bj().strftime("%Y%m%d")
