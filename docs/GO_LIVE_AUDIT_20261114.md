## 一、放行门禁现状（机器结论，非人工意见）

`data/runtime/state/go_live_gate.json`（checked_at = 2026-11-13 21:50:58）：

```text
allowed = false
n_trades = 167 | independent_days = 13 (< 20)
avg_pnl = -2.43%/笔（悲观口径，含出场轮询滞后滑点 0.5%；乐观口径 -2.01%）
win_rate = 16.8% | profit_factor = 0.26 (< 1.2) | CI95 下限 = -2.05% (≤ 0)
```

**不放行理由（全部 5 条同时成立）**：
1. 独立样本不足：13 个交易日 < 20（167 笔成交落在同一波段，不算 167 个独立证据）
2. 期望值为负：-2.43%/笔，数学上必亏
3. 盈利因子 0.26 < 1.2（总亏损远大于总盈利）
4. 期望值的 95% 置信下限 -2.05% ≤ 0（无法排除「其实是亏的」）
5. **7 个战法已红牌**（样本 ≥20 且期望 ≤ -1%/笔）：
   P5-13C -2.67%(31笔) / P5-12A -2.55%(21) / P5-05A -2.44%(74) / P5-05C -1.96%(49) /
   P5-05B -1.91%(48) / P5-13B -1.56%(54) / P5-13A -1.39%(55)

门禁阈值定义见 `core/go_live_gate.py`（MIN_TRADES=60 / MIN_INDEPENDENT_DAYS=20 / MIN_PROFIT_FACTOR=1.2 / 红牌线 -1%）。
门禁为 fail-closed 设计：无结论、过期（>3 天）、评估异常都判为不放行；`assert_live_allowed()` 会抛异常。

## 四、上线阻断项（本轮新发现，按优先级）

### P0-1 策略期望为负（真钱阻断主因）
见 §一/§二。这不是工程问题，关闭条件是门禁 6 条全部转绿（见 §五）。

### P0-2 网络单点 → 数据/推送/告警「三停合一」
- **实测**：Windows 系统代理指向 `127.0.0.1:7897`（Clash 类本地代理），该端口当前死亡（TCP 探测失败）；
- 11-14 15:16~15:37 期间 Tushare `trade_cal` 连续失败（重试耗尽 → 按非交易日跳过）、**企微告警同样发不出去**（告警与数据走同一路由，直连兜底也未生效）；
- 后果：代理一死，**数据停 + 推送停 + 告警停且无人知晓**（09:11 归因推送成功 → 15:16 全失败，说明代理 Availability 是间歇性的，更难察觉）。
- 修法建议：① 应用内显式网络健康自检（代理/直连双探活，失败进本地可见的告警通道）；② 关键域名绕过代理直连（qyapi.weixin.qq.com / api.waditu.com 本可直连）；③ 告警通道与数据通道解耦（至少文件落盘 + UI 红牌 + 可选第二通道）。

### P0-3 企微 webhook key 明文进 `sniper.log`
- 告警发送失败时异常串包含完整 webhook URL（含 key），长期追加进日志；日志会被排查/分享。
- 修法：日志脱敏（发送前对 URL query 中的 key 做 `mask`），历史日志轮转清理。

### P1-4 双 daemon 并存（进程互斥缺口，需复验）→ ✅ 已复验关闭（审计误读）
- **实测**：15:34:51 同一秒启动两个 `auto_sniper_daemon.py`：
  - pid 15640（`_pyenv\python311`）→ 正常持锁、写日志、干活；
  - pid 8316（`_pyenv\venv`）→ 悬停 7 分钟仅 0.015s CPU / 4.5MB 内存，**未按设计以 exit code 2 退出**。
- **复验结论（2026-11-14 17:00）**：`ParentProcessId(15640) = 8316` —— 8316 是 venv 的
  **启动器 stub（重定向器）**，15640 是它 exec 出的基础解释器子进程。**这是同一个逻辑
  daemon 的正常父子形态，不是双实例**。
- **互斥契约实测**：并发启动第二个真实实例 → 立即 `EXIT_CODE=2`（"检测到已有
  auto_sniper_daemon 进程在运行"）。单实例锁（msvcrt 字节锁）工作正常。**本项关闭。**
- 遗留提示：未来审计看到「两个 python.exe」先查父子关系，勿误报。

### P1-5 数据主接口退化（walk 了一周多）
- `daily` 主接口自 11-05 起连续 `ok=false`，靠 `daily_by_date` 备链维持（行数正常 5571~5574）；
- `forecast` / `margin_detail` 常态性缺失（非关键字段，但选股因子若依赖须确认降级语义）。

### P1-6 交易日历依赖在线接口

### P1-7 周末作业守卫存疑
- 11-14（周六）08:40「模拟盘初始化」、15:09「模拟盘收盘结算」仍执行（bj_daily_jobs_done.json）；
- 需确认：trade day index 不因非交易日虚增、结算幂等、不会重复扣费/重复净值行。

### P1-8 模拟盘净值链断档
